# 文章概念网络与评论关闭

日期：2026-10-16。

## 变更

文章原有思维导图仅将标题转成 Mermaid 文本，与现有 Mermaid 渲染入口不匹配。现改为直接渲染 SVG，在中文文章与英文版本中显示文章、章节、子章节和正文概念。

- 实线表示章节或概念的所属层级。
- 虚线连接不同章节出现的同一概念，不代表因果或推导关系。
- 概念来自正文强调、行内术语、具名链接与实际出现的领域词汇。每节最多取 8 个标记候选和 6 个词汇候选，控制图的规模；不是全文语义的穷尽表示。
- 节点详情保留来源片段，并可跳到原文章节。支持层级、分支、查找、缩放、键盘访问、画布滚动与 SVG 导出。
- 源数据在构建时提取，不调用外部 AI 服务；代码块不参与概念提取。

维护入口为 `src/utils/article-concept-graph.ts` 与 `src/components/features/Mindmap.svelte`。领域词汇只是候选词表，未在正文出现的词不会进入图；新增领域可以扩充词表。

## 评论

排查发现旧 Giscus 仓库／分类 ID 不匹配，Discussions 未开启，Giscus 应用也未授权。用户随后明确决定不要评论，因此最终将 `commentConfig.type` 设为 `none`，不再加载评论区。排查期间临时开启的 Discussions 在确认讨论数量为 0 后恢复关闭。没有创建或发送测试评论，没有安装第三方应用。
