# 第八轮：持续修订的智能问题地图

智能可以先作为一组与任务、环境、学习历史和资源有关的能力问题来研究；这一工作性视角不是所有路线共享的定义，也不预设能力、意义、生命、价值或体验相互等同。

这是对已有路线、结论和有限检验的一次编辑性综合，不是新实验或统一智能定义。9个问题域是导航安排，不预设彼此互斥或穷尽。
