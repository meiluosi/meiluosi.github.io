# 九个问题域：当前判断、强反方与检验

<a id="performance"></a>

## 表现、能力与泛化

**当前判断：** 表现是特定任务、评分和资源约束下的观测；跨任务能力与学习效率是需要进一步检验的推断。

**强反方／替代解释：** 如果不同任务共享评分偏差、训练数据或工具支持，共同高分未必反映可迁移能力。

**可区分的下一项检验：** 预先指定新任务与留出单位；记录训练、推理和工具预算，观察能力排序是否跨条件保持。

**相关第四轮结论：** [p1](../round-four/integration/review.md#p1)、[p6](../round-four/integration/review.md#p6)。**既有问题卡：** [q-performance-capability](questions.md#q-performance-capability)、[q-learning-generalization](questions.md#q-learning-generalization)。

<a id="mechanism"></a>

## 相关结构与产生机制

**当前判断：** 因素模型可描述共同变化；因果机制、算法和实现需要不同证据。

**强反方／替代解释：** 相同相关结构可能由不同共同原因或测量过程产生，损伤效应也可能反映断连与代偿。

**可区分的下一项检验：** 比较能拟合相同数据的竞争模型，设计能让它们预测不同结果的操纵。

**相关第四轮结论：** [p2](../round-four/integration/review.md#p2)、[p3](../round-four/integration/review.md#p3)、[p6](../round-four/integration/review.md#p6)。**既有问题卡：** [q-factor-mechanism](questions.md#q-factor-mechanism)、[q-neural-mechanism](questions.md#q-neural-mechanism)、[q-model-representation](questions.md#q-model-representation)。

<a id="development"></a>

## 学习、发展与开放环境

**当前判断：** 适应不能只看既有技能的即时分数，还要比较新经验、交互历史和变化环境下的学习。

**强反方／替代解释：** 所谓新能力可能来自预训练、工具或评价泄漏；环境越开放也不意味着一定更智能。

**可区分的下一项检验：** 隔离先验经验、训练预算和评估任务，追踪学习曲线与环境变化后的表现。

**相关第四轮结论：** [p1](../round-four/integration/review.md#p1)、[b3](../round-four/integration/review.md#b3)。**既有问题卡：** [q-development-openended](questions.md#q-development-openended)。

<a id="boundary"></a>

## 身体、环境与系统边界

**当前判断：** 系统边界应随解释目标确定；有用的功能整体与认知构成或主观主体并非同一个主张。

**强反方／替代解释：** 工具或环境可能只是可靠外因；移除后性能下降不自动证明其属于心智。

**可区分的下一项检验：** 分别操纵当下工具、互动反馈和发展历史，检查替代因果结构。

**相关第四轮结论：** [b1](../round-four/integration/review.md#b1)、[b2](../round-four/integration/review.md#b2)、[b3](../round-four/integration/review.md#b3)、[b4](../round-four/integration/review.md#b4)、[b6](../round-four/integration/review.md#b6)。**既有问题卡：** [q-agent-environment](questions.md#q-agent-environment)、[q-life-cognition](questions.md#q-life-cognition)、[q-system-boundary](questions.md#q-system-boundary)。

<a id="collective"></a>

## 群体协作与文化

**当前判断：** 群体任务的共同变化与协作过程是相关但不同的问题，文化传递还涉及代际组织和历史。

**强反方／替代解释：** 共同因素可能受成员能力或任务设计驱动；一次成功协作不证明稳定群体能力或文化累积。

**可区分的下一项检验：** 区分留出任务、群体和研究；操纵成员组合与协作过程，并按版本核对原始模型。

**相关第四轮结论：** [p4](../round-four/integration/review.md#p4)、[p5](../round-four/integration/review.md#p5)、[b5](../round-four/integration/review.md#b5)。**既有问题卡：** [q-cultural-cumulation](questions.md#q-cultural-cumulation)。

<a id="semantics"></a>

## 表征、指称与意义

**当前判断：** 内部概念角色、外部指称与交际意图是不同目标；外部锚点能增加区分，但不自动解决理解归属。

**强反方／替代解释：** 纯内部关系可能欠定指称；反过来，仅有外部正确对应也未必说明系统具有完整语义能力。

**可区分的下一项检验：** 固定意义判据并构造内部角色相同、外部指称不同的对照，再测试在新情境中的使用。

**相关第四轮结论：** [m1](../round-four/integration/review.md#m1)、[m2](../round-four/integration/review.md#m2)。**既有问题卡：** [q-compression-semantics](questions.md#q-compression-semantics)。

<a id="experience"></a>

## 访问、意识与解释

**当前判断：** 可报告、可访问与有体验应分别记录；不同意识理论的功能和物理桥接假说不应混成一项。

**强反方／替代解释：** 报告和神经相关可能只是任务、注意或测量的替代解释；没有报告也不自动证明没有体验。

**可区分的下一项检验：** 比较理论预注册的相互排斥预测，区分原指标、追加分析和辅助假设。

**相关第四轮结论：** [m3](../round-four/integration/review.md#m3)、[m4](../round-four/integration/review.md#m4)、[m5](../round-four/integration/review.md#m5)、[m6](../round-four/integration/review.md#m6)。**既有问题卡：** [q-consciousness-explanation](questions.md#q-consciousness-explanation)。

<a id="norms"></a>

## 资源、目标与价值

**当前判断：** 效率和合理性依赖目标、资源和环境；价值判断需要公开受益者、损害和规范前提。

**强反方／替代解释：** 最优分数可能优化了有缺陷的目标，且不同群体对代价和收益有合理分歧。

**可区分的下一项检验：** 同时报告资源、利益分配和替代目标，比较在目标变化时系统的行为。

**相关第四轮结论：** [p1](../round-four/integration/review.md#p1)、[p6](../round-four/integration/review.md#p6)。**既有问题卡：** [q-utility-resources](questions.md#q-utility-resources)、[q-wisdom-norms](questions.md#q-wisdom-norms)。

<a id="physical"></a>

## 形式、实现与物理假设

**当前判断：** 概率形式相似与某种物理实现是不同命题；物理主张应说明能区分其他实现的证据。

**强反方／替代解释：** 数学拟合优势未必支持特定物理机制；微观假说也未必对解释能力产生必要增益。

**可区分的下一项检验：** 预先指定经典和量子模型的不同预测、可测物理条件及失败标准。

**相关第四轮结论：** [p6](../round-four/integration/review.md#p6)、[m4](../round-four/integration/review.md#m4)。**既有问题卡：** [q-quantum-implementation](questions.md#q-quantum-implementation)。

这些检验均为建议，不表示已经实施。问题域的分类只是阅读索引，并非对应理论天然边界。
