# 第三轮15项问题卡与本地图

每张卡只分配一个主要导航入口；跨问题域的关系仍在具体比较中保留。这个映射不代表原卡的所有争论已解决，也不表示所提出的检验已执行。

<a id="q-model-representation"></a>

## 模型与表征：同一个词承担哪些不同任务？

哪些表示服务于解释、推理、预测或控制？这些功能能否互相推出？

地图入口：[相关结构与产生机制](map.md#mechanism)。

[原问题卡](../round-three-a/questions/q-model-representation.md) · [原图](../round-three-a/questions/q-model-representation.mmd)

既有对照：先对齐四项：表示什么、用于什么运算、由什么经验获得、通过什么失败检验。共享“模型”一词不足以判定这些研究相互支持或相互否定。 对结构表示还须分别检查可表达性、可取回性、可学习性及实际过程，不能从其中一项自动推出其余各项。

状态：原卡记录为 proposed-not-run；本轮未将提议检验标为已运行。

<a id="q-learning-generalization"></a>

## 学习与泛化：究竟把什么能力推广到了哪里？

理论学习保证、组合任务成绩和从经验形成规则，能否在同一尺度上比较？

地图入口：[表现、能力与泛化](map.md#performance)。

[原问题卡](../round-three-a/questions/q-learning-generalization.md) · [原图](../round-three-a/questions/q-learning-generalization.mmd)

既有对照：为每项结果列出训练时知道什么、测试改变了什么、允许多少经验与计算，再比较机制。某种切分上的成功或失败，都不能自动推广为所有任务上的系统性结论。

状态：原卡记录为 proposed-not-run；本轮未将提议检验标为已运行。

地图入口：[身体、环境与系统边界](map.md#boundary)。

[原问题卡](../round-three-a/questions/q-agent-environment.md) · [原图](../round-three-a/questions/q-agent-environment.mmd)

既有对照：先说明要解释的是行为成功、学习过程、经验意义还是系统构成，再选择实验与论证。可存续、节省控制和认知能力不能未经论证互相替代。

<a id="q-performance-capability"></a>

## 表现与能力：高分支持了哪一种解释？

如何从一次成功走到跨任务的能力判断？

地图入口：[表现、能力与泛化](map.md#performance)。

[原问题卡](../round-three-b/questions/q-performance-capability.md) · [原图](../round-three-b/questions/q-performance-capability.mmd)

既有对照：分数是起点。至少要说明评价对象、任务分布、经验与资源、统计不确定性，以及想将结论推广到哪里。同样输出可以支持操作性成功，却不足以唯一说明内部过程；统一提示也不能消除训练经历差异。

状态：原卡记录为 proposed-not-run；本轮未将提议检验标为已运行。

<a id="q-factor-mechanism"></a>

## 共同因素与机制：相关结构能确定什么？

共同变化是否足以识别一个共同心理原因？

地图入口：[相关结构与产生机制](map.md#mechanism)。

[原问题卡](../round-three-b/questions/q-factor-mechanism.md) · [原图](../round-three-b/questions/q-factor-mechanism.mmd)

既有对照：稳定共同结构不必对应唯一生成机制；反过来，这也不使结构描述失效。Spearman原文已保留“功能或功能群”的措辞。本批精确合成核验给出一个观测等价例子，但没有运行POT或真实人群实验。均值比较还另需载荷、截距等约束。

状态：原卡记录为 proposed-not-run；本轮未将提议检验标为已运行。

<a id="q-utility-resources"></a>

## 效用与资源：对谁、在何种环境中合理？

不同理性路线是否在优化同一个对象？

地图入口：[资源、目标与价值](map.md#norms)。

[原问题卡](../round-three-b/questions/q-utility-resources.md) · [原图](../round-three-b/questions/q-utility-resources.mmd)

既有对照：需要对齐目标函数、环境分布、先验、时间尺度和可执行操作，才能比较“最优”“满意”和“适应”。快速规则不天然合理，复杂策略也不天然浪费；一个不计内部成本的理想指标不能直接用来裁决资源敏感的过程模型。

状态：原卡记录为 proposed-not-run；本轮未将提议检验标为已运行。
