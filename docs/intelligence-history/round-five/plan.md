# 第五轮：路线演进时间线的网站化

## 目标

将第二轮至第三轮已审校的20条路线转换为正式网站上的可阅读时间线。节点呈现问题、方法、主张定位、前提、限制、下一问和来源实际读段；图、数据和来源可以继续维护。第四轮综合与本轮路线页面双向连接。

## 样板与推广

先以学习效率（形式理论与基准）、心理测量（构念与样本）和心灵哲学（哲学论证与解释层级）做三种不同样板，逐项比较输入节点、原来源和网站输出。通过后按相同规则推广20条路线；允许多个路线引用同一节点。年代不明的古典文本独立排列，不以译本年代代替原作年代。

## 数据与证据规则

- `research-index.json` 指定各路线使用哪个批次的节点；回到相应批次 `research.json` 读取机制、前提、限制、来源与主张，不以索引摘要代替原始数据。
- 当前索引已有书目更正时，展示更正与依据，同时保留原作者记录；不改历史快照。
- 同ID不同批次可能有不同读段；一条路线呈现该索引选定的批次，来源与其实际读段保持绑定。历史关系只展示原已登记的、两端均属于该路线的关系，保留类型、定位和编辑判断；不从先后推断影响。
- 每条路线的SVG、Mermaid及可下载JSON由脚本生成；后续修改批次原始研究数据并更新历史索引后再运行生成器，直接改生成图会在下次重建时被覆盖。
- 本轮只重用现有阅读与审校，不宣称新增原典阅读、历史关系考证或经验复现。第一轮未映射候选与各路线其他未读部分继续保留。

## 验收

1. 数据覆盖与溯源：20条路线、每条节点与索引逐一相符；每个节点的原批次、问题、机制、前提、限制、主张和来源逐项可追溯，缺失字段如实显示。
2. 用户路径：路线首页、综合研究与单路线时间线互通；节点图可点击并支持键盘；源文链接、阅读范围与定位可见，无脚本时仍可阅读完整节点清单。
3. 维护：生成一致性、SVG/XML、Mermaid及下载链接，保留历史数据；对三个样板和古典节点特别核对。
4. 工程：项目诊断、类型检查、生产构建；浏览器桌面／手机、过滤、深链接、空状态与不依赖脚本阅读。
