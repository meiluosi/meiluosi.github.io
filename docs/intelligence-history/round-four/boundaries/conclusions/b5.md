# 互动提高成功机会，不等于个人识别能力提高

类型：conditional-synthesis；[结论总览](../conclusions.md)。

## 条件与推理

区分点击份额、接触机会、校正后的相对点击指标和独立识别任务；互动与个人的分析单位同时保留。

## 最强异议

互动论者未必要求个人脱离互动就能识别对象；因此没有独立识别优势并不反驳互动组织本身具有解释价值。

## 回应与收窄

接受这个限定：结果约束的是能力归属，仍支持研究互动动力学。原文非显著差异也不等于统计等效；不能由此断言个人绝无识别能力。
