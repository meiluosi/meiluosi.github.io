# 比较框架的边界与时间扩展

沿用[第一阶段八维框架](../framework.md)，不将不同证据合成为一个强弱分数。本阶段增加：

| 维度 | 要回答什么 | 推论限制 |
| --- | --- | --- |
| 边界判据 | 分析方便、因果必要、功能整合，还是生产组织／认知构成？ | 不同判据给出不同问题；要明说采用哪一个。 |
| 时间尺度 | 瞬时支持、试次历史、学习发展还是跨代演化？ | 测试时移除不独自识别训练中的贡献。 |
| 介入位置 | 改变信息、时延、反馈、身体状态还是组织再生产？ | 多条路径同时变化时不能指定唯一机制。 |
| 状态与历史 | 当前状态是否匹配；历史的顺序和次数是否分别控制？ | 相同暴露次数不必产生相同状态；不假设过去脱离现在起作用。 |

每条综合结论保留原文定位、桥接条件、最强异议、回应、可区分检验和未决边界。实验设计与执行结果分开，理论归属与可观测预测分开。
