## A：历史通过当前状态起作用

h从0开始，四步按h(t+1)=(h(t)+e(t))/2更新。测试时停止学习，y=h+u，u为当前支持0或1；y是任意读数，不是概率或能力分数。另设测试前把h重置为0的条件。

| 历史 | 状态轨迹（含初始值） |
| --- | --- |
| 1100 | 0 → 1/2 → 3/4 → 3/8 → 3/16 |
| 1111 | 0 → 1/2 → 3/4 → 7/8 → 15/16 |
| 0000 | 0 → 0 → 0 → 0 → 0 |
| 0011 | 0 → 0 → 0 → 1/2 → 3/4 |

## B：同轨迹与不同反馈

闭环L同步更新x′=(x+e)/2、e′=(e+x)/2；回放R的e来自L未扰动轨迹，不读取当前x。初值x=0、e=1，六次更新。扰动在t=2更新前将x设为1、保留e。

| 时刻 | L基线(x,e) | R基线(x,e) | L扰动(x,e) | R扰动(x,e) |
| --- | --- | --- | --- | --- |
| 0 | (0, 1) | (0, 1) | (0, 1) | (0, 1) |
| 1 | (1/2, 1/2) | (1/2, 1/2) | (1/2, 1/2) | (1/2, 1/2) |
| 2 | (1/2, 1/2) | (1/2, 1/2) | (1, 1/2) | (1, 1/2) |
| 3 | (1/2, 1/2) | (1/2, 1/2) | (3/4, 3/4) | (3/4, 1/2) |
| 4 | (1/2, 1/2) | (1/2, 1/2) | (3/4, 3/4) | (5/8, 1/2) |
| 5 | (1/2, 1/2) | (1/2, 1/2) | (3/4, 3/4) | (9/16, 1/2) |
| 6 | (1/2, 1/2) | (1/2, 1/2) | (3/4, 3/4) | (17/32, 1/2) |

基线完全相同；t=3时闭环e为3/4，回放e为1/2。两者的x在t=3仍同为3/4，到t=4才不同。不要把传播时延抹去。
