# 时间尺度与耦合：预先方法协议

2026-10-28，先于实现保存。以下是本站构造的有限模型，不拟合儿童、驾驶舱或生物实验，不裁决认知构成。用有理数精确计算，无随机采样，无显著性检验。

## A：发展历史与当前支架

状态h初始为0；四步学习按h(t+1)=(h(t)+e(t))/2更新，e取0或1。测试时冻结学习，表现读数y=h+u，u为当前可用支架（0或1）；y不是概率或真实能力量表。

预定条件：全0历史、全1历史、1100、0011；各测试u=0和u=1。核对：

1. 全1历史终态15/16，全0历史为0。
2. 当前支架移除的损失在所有历史中均为1，故相同移除效应不足以推断相同发展历史。
3. u相同仍保留历史造成的状态差异，区分学习阶段介入与测试阶段介入。
4. 相同暴露次数的1100与0011分别得到3/16、3/4，次数匹配不保证顺序匹配。
5. 若将测试前状态h重置为同一值，历史差异消失；本例历史效应由当前状态中介，不主张脱离状态的神秘历史作用。

## B：真实反馈与轨迹回放

六次同步更新，从x(0)=0、e(0)=1开始。闭环模型L为x(t+1)=(x(t)+e(t))/2、e(t+1)=(e(t)+x(t))/2。回放模型R只更新x，环境输入取L未扰动时预先记录的e序列；R的环境不读取当前x。

6. 未扰动时两模型的x和e轨迹完全相同。
7. 在t=2更新前把x设为1、保留e，闭环下一时刻e=3/4，回放下一时刻e=1/2；两者的反馈结构可被此受控扰动区分。
8. 无扰动负控制保持一致；同步更新不得写成先改x再用新x改e。
