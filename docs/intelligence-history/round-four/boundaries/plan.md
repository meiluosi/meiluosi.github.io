# 第四轮第二阶段：系统边界与发展

2026-10-28启动。研究问题：工具、互动伙伴和生命过程在什么条件下进入解释单位？在线贡献、发展依赖与认知构成分别需要什么证据？

沿用第一阶段八维框架，增加边界判据、时间尺度、介入位置与状态历史字段。以驾驶舱／外部记忆、发展中的动作、生命自主性及社会互动为比较案例，补读支持论证与强反方。不以“耦合”一词替代具体机制，不把有用、必要、构成认知当成同一判断。

## 交付条件

1. 原典按实际版本、阅读范围和定位登记；旧笔记保持快照，本阶段增量单独记录。
2. 比较矩阵与条件性结论包含最强异议、回应、可区分条件及未决事项。
3. 编辑性比较与有文献依据的争论关系分开；提供可编辑演进图、边界比较图与交互工作台。
4. 保存预先方法协议后完成精确合成核验，只验证时间尺度和因果推论，不冒称原实验复现或哲学争议解决。
5. 形成可执行但尚未执行的经验研究方案，列明操纵检验、停止条件及实施前待定项。
6. 接入统一入口，检查旧快照、生成一致性、文档路径、交互、桌面／手机布局及项目构建。
