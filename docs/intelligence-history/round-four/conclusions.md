# 条件性结论与证据审计

- [成绩支持能力判断，需要任务与资源条件](conclusions/p1.md)：一次成绩首先是特定系统在特定任务、评分和资源下的结果。跨任务能力与技能获取效率需要额外设计；二者不是同一个测量目标。
- [共同变化约束解释，却不唯一识别共同原因](conclusions/p2.md)：共同因素可压缩相关结构并服务预测；把它解释为单一共同心理原因，需要排除能生成同样观察的替代机制。
- [损伤效应可以约束因果角色，计算解释仍需过程证据](conclusions/p3.md)：可靠的损伤结果可以约束某结构在所测条件中的因果作用；仅凭性能下降与位置映射，仍不能唯一推出该结构执行的算法。
- [群体共同因素与协作机制，需要分别审计](conclusions/p4.md)：所读群体研究支持若干任务中的共同变化，但成员能力和协作过程的预测贡献存在分歧。任务、计分、样本与沟通记录不对齐时，不能把分歧压成“只有成员”或“只有协作”。
- [预测验证与报告指标必须保留各自口径](conclusions/p5.md)：留出任务的预测、留出群体的预测、因子提取的方差和平均提取方差回答不同问题；相似百分比不能直接拼成同一证据。
- [有限证据下，机制结论应写成受检模型集合](conclusions/p6.md)：每次观察或干预可排除部分竞争模型，但模型在已测条件中等价，并不保证在新情境中等价。综合结论应保留仍未区分的模型与下一项检验。
