# 共同变化约束解释，却不唯一识别共同原因

共同因素可压缩相关结构并服务预测；把它解释为单一共同心理原因，需要排除能生成同样观察的替代机制。

类型：conditional-synthesis；[返回结论审计](../conclusions.md)。

## 条件与推理

区分统计因子、因果变量与具体过程；比较者必须对同一数据口径提出预测。

## 最强异议与回应

互惠模型也有未识别参数；给出另一个模型不证明它就是真实机制。

因此保留两类解释：反例推翻的是“相关结构唯一决定机制”的推论，没有判定真实g的起源。

## 可以区分解释的检验

固定竞争模型与测量模型，用纵向／可解释的干预数据检验它们对变化与迁移的不同预测。

本轮高斯反例是不同于互惠发展模型的独立数学例；不宣称复现van der Maas。
