# 跨路线比较框架

证据强弱取决于它是否能回答当前主张。经验结果、形式证明、概念论证不合并成一个分数；“干预”也不自动高于所有其他证据。自然病损、随机操纵与理想do算子分别登记。

| 比较维度 | 要核对什么 | 推论边界 |
| --- | --- | --- |
| 研究单位 | 个体、群体、神经系统、算法或形式模型；边界是否含工具和外部记忆？ | 单位不同，不能把g、c、网络节点或模型参数直接当成同一变量。 |
| 目标主张 | 要描述成绩、预测新任务、解释作答过程，还是识别物理实现／讨论体验？ | 先写要回答的问题，不能让取得的指标替换解释目标。 |
| 任务与评分 | 任务集合、评分函数、时间、测试顺序、题目暴露和评分可靠性。 | 不同任务或评分变化可能改变相关结构。 |
| 资源与经历 | 训练数据、先验、时间／算力、人数、沟通界面、发展史。 | 同等成绩不表示同等学习效率；资源相同也未必先验相同。 |
| 观察与测量 | 样本与抽样、信度、缺失、指标／潜变量关系、群体内和群体间层级。 | 群体间相关不直接给出个体内变化规律。 |
| 识别与竞争解释 | 拟合了哪些模型？有哪些模型可生成相同证据？是否存在饱和或欠识别？ | 单模型拟合优良不等于排除了其他生成机制。 |
| 干预与机制 | 实际改了什么？是否同时影响其他环节？哪些过程预测可被反驳？ | 自然损伤、理想do操作、随机训练干预必须分开。 |
| 迁移与版本 | 预测留出任务还是留出人群／环境？读取哪个版本及更正？ | 结论范围由实际检验边界决定，不能随标题或时间更新而扩大。 |

## 结论审计规则

1. 先陈述目标主张，再决定何种证据相关，避免让手头指标替代目标。
2. 原文主张链接具体版本与定位；本站推断明确列出桥接前提。
3. 记录竞争解释的最强版本、何种证据会区分它们，以及尚未执行的检验。
4. 将材料可得、实际阅读、原文报告和独立核验分开。
5. 有限模型的反例可否定一般逻辑推论，不能替代实际机制的经验识别。
