# 第四阶段执行与验收范围

本阶段承接前三篇共同问题，不新增文献阅读或招募实验。

1. 逐条检查18条结论的目标、分析单位、证据性质、最强反方、范围和可区分条件；原文不覆盖，修订另存。
2. 统一来源身份：作品、版本、载体、关联文件和实际读段；补充文件、更正和同项目材料不作为独立重复验证。
3. 以Astro原生页面提供三篇综述、31个来源页、18条修订对照、文献筛选与9项研究队列；路线、文献架和文章入口双向连接。
4. 公开可编辑SVG／Mermaid、模型协议、精确结果与阅读笔记；不携带第三方原文PDF。
5. 修正与共同复核直接冲突的三处演示，用现有核验模型说明历史／支持、映射识别和报告依赖；其余旧演示仍未全面审校。
6. 验证93份历史与前三篇核心材料指纹、68项生成结果、正文与主张锚点、构建产物所有本地链接、键盘操作、无脚本阅读和桌面／手机呈现。
7. 检查通过后，将第四轮标为指定范围完成；9项设计、数据复算、专项阅读和公网部署继续分别记录。

维护入口：research.json是修订层；前三篇research.json是证据层。网站通过src/data/intelligenceResearch.ts读取两层；下载资源由scripts/generate-intelligence-integration.mjs生成。新增结论或来源后先更新对应层，再生成、检查、构建和验收。
