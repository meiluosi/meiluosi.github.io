# 六条条件性结论

## 先说清所要解释的“意义”

外部指称、交际意图和内部概念角色是不同的解释目标。评价理解时，必须先固定目标，再判断证据；某项缺失不能不加条件地推出所有意义均为零。

## 落地增加约束，不能跳过主体与系统层级

在明确的指称识别任务中，外部锚点能够排除歧义；但这种识别成果与系统拥有何种理解、是否具有主观意义，仍是不同的主张。
