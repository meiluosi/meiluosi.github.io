# 解释对象与桥接前提

沿用[第一阶段比较框架](../framework.md)及[第二阶段时间与边界扩展](../boundaries/framework.md)。这里的连接表示需要论证的推理，不是证明“体验由左边自动产生”。

![五种桥接问题](bridge-map.svg)

| 维度 | 问题 | 边界 |
| --- | --- | --- |
| 解释对象 | 表现、指称、交际意图、概念角色、访问还是体验？ | 先对齐问题；不以同一词汇假定同一构念。 |
| 归属单位 | 操作者、子系统、整体还是物理实现？ | 部分的性质不直接传递给整体，反向也不自动成立。 |
| 桥接性质 | 定义、理论公设、经验假说还是测量规则？ | 记录推理类型；相关不等于构成或必要性。 |
| 版本与预测 | 哪个版本、何时锁定、何种分析、何种失败条件？ | 新版本不回写旧承诺，探索结果不追认成原预测。 |
| 观测与干预 | 改变的是体验、注意、任务、报告还是记录灵敏度？ | 无报告或可解码都不是无需论证的体验真值。 |
| 修订与风险 | 哪项新证据会迫使放弃当前解释？ | 辅助前提须独立校验，不能无限添加事后豁免。 |

| 从何种证据 | 走向何种主张 | 桥接类型 | 需要说明 | 风险与结论 |
| --- | --- | --- | --- | --- |
| 可用的语言表现 | 指称／交际意义 | 经验识别条件 | 训练与交互是否约束对象和意图？ | 形式分布相同可对应不同映射；[m1](conclusions/m1.md)、[m2](conclusions/m2.md) |
| 内部表征与推理 | 概念角色意义 | 语义理论＋经验检验 | 角色论是否适用，关系是否有稳定因果作用？ | 探针相关或流畅回答不足以证成角色；[m1](conclusions/m1.md)、[m2](conclusions/m2.md) |
| 可用信息与实际报告 | 意识访问 | 操作定义＋测量假说 | 报告要求、注意和记忆怎样影响指标？ | 可报告不等于每次实际报告；[m3](conclusions/m3.md) |
| 神经机制与因果结构 | 现象体验 | 解释主张＋生物实现假说 | 全局可用、同一主张或心理物理原则？ | 数学量、代理信号和体验不能互换；[m4](conclusions/m4.md) |
| 预先约定的神经预测 | 理论的支持或挑战 | 经验推断 | 版本、辅助条件、有效测量和分析身份？ | 失败预测不等于全部理论的总裁决；[m5](conclusions/m5.md)、[m6](conclusions/m6.md) |
