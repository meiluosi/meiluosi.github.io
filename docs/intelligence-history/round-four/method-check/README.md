## 三变量高斯模型

共同原因模型F：Xi=(G+ei)/√2，所有G、ei独立标准正态。

顺序模型C：X1=U1；X2=X1/2+U2；X3=X1/3+X2/3+U3。独立零均值正态噪声方差为1、3/4、2/3。

两者均为零均值多元高斯，协方差完全相同（对角1，非对角1/2），因此这里相同的不只是相关矩阵，而是整个观察联合分布。行列式为1/2。脚本将F重参数化为方差1/2的共同因子与误差，以有理数精确运算。

| 干预 | F的均值(X1,X2,X3) | C的均值(X1,X2,X3) |
| --- | --- | --- |
| do(X1=1) | 1, 0, 0 | 1, 1/2, 1/2 |
| do(X2=1) | 0, 1, 0 | 0, 1, 1/3 |

干预替换目标变量方程并删除其入边；条件化X1=1不是相同操作。两种模型的E[X2|X1=1]均为1/2，但F的E[X2|do(X1=1)]为0。

## 有限干预也不能穷尽机制

D1为Y=A∧B，D2为Y=A。只在B=1的情境中观察并改变A，两个模型均给出相同结果；在A=1、B=0时输出分别为0、1。

| A | B | D1 | D2 | 原已测情境 |
| --- | --- | --- | --- | --- |
| 0 | 0 | 0 | 0 | 否 |
| 0 | 1 | 0 | 0 | 是 |
| 1 | 0 | 0 | 1 | 否 |
| 1 | 1 | 1 | 1 | 是 |
