# 表现到机制的方法核验协议

2026-10-28，先于实现保存。性质：本站有限模型的数学反例，非心理或神经研究复现。

## 问题与预设模型

设相互独立的标准正态G、e1、e2、e3。共同原因模型F：Xi=(G+ei)/√2。故Var(Xi)=1，任意两项Cov=1/2。

顺序模型C：X1=U1；X2=X1/2+U2；X3=X1/3+X2/3+U3。独立零均值正态噪声方差分别为1、3/4、2/3。其联合分布应与F相同。此模型仅作精确反例，不是van der Maas的互惠发展模型。

对两模型分别进行理想外科干预do(X1=1)。F中G分布不变，预期E[X2]=E[X3]=0；C中预期分别为1/2、1/2。再进行do(X2=1)，F中E[X1]=E[X3]=0；C中分别为0、1/3。

干预局限反例：D1输出Y=A∧B；D2输出Y=A，仅在B恒为1的已测情境中测试。两者观察相同、do(A=0/1)结果相同；把B设为0并令A=1时才区分。因而已测干预集相同也不保证完整机制唯一。

## 预先验收条件

1. 使用有理数矩阵计算两模型协方差，逐项等于对角1、非对角1/2；不得用有限随机样本的近似相关代替。
2. 用独立的顺序结构矩阵与手算目标交叉核对，两个协方差行列式均为1/2。
3. 两组干预的均值逐项符合上述预期；干预需删除目标入边，不能把条件期望当干预。
4. 穷举二元电路：旧情境和已测干预保持等价；新情境产生区分。记录全部条件而非仅报告成功反例。
5. 保存参数、精确结果、协议与脚本指纹；图从结果生成。任何失败须解释或修订模型并保留原协议。

## 可以和不可以推出什么

可以证明：在上述模型类内，观察等价不保证干预等价；已测干预等价也不保证新情境等价。不能据此判断真实人的g、群体c或某脑区必然由哪个机制产生。经验研究还需要测量信度、操纵特异性、样本覆盖和外部效度。
