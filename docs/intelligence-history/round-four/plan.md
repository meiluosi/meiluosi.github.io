# 第四轮综合研究执行计划

2026-10-28启动。第一阶段以一个完整综合样板建立比较与证据审计方法；后续主题分阶段扩展。第四轮整体不以首篇完成为完成。

## 第一阶段的研究问题

从表现、相关结构与干预结果，分别能推出哪些关于能力与机制的结论？比较个体测量、神经机制、群体表现，并用形式反例检验推理是否越界。

验收单位是条件明确的综合结论：每条结论须列研究对象、任务与资源、证据来源和定位、竞争解释、可区分条件、尚未排除的问题。原文主张、本站综合推断与独立方法核验分别记录。

## 交付与验收

1. 跨批覆盖注释：保留七份第一至三轮数据指纹；明确同ID、章节部分覆盖、相关但不同作品；修正当前索引过时的未来时态。
2. 比较框架：统一分析单位、构念、任务、资源、统计识别、干预与迁移条件；提供复用模板。
3. 关键来源补读：因果效度主张、统计结构的竞争生成解释、神经损伤与微处理器反例、群体能力的原始研究／批评／后续综合及更正；按实际版本与范围建文献笔记。
4. 综合样板：比较矩阵、条件性结论与异议台账、可编辑SVG和Mermaid、能进入原文笔记的交互阅读页。
5. 独立方法核验：先保存协议，再执行有限模型的精确计算；不得冒充经验研究复现。
6. 后续方案：可区分竞争解释的研究设计、停止条件与实施前待定项；未执行实验单列。
7. 接入本地统一入口，核验生成一致性、链接、旧快照、桌面／手机交互与项目检查。

## 第二阶段交付与第三阶段起点

[系统边界与发展工作台](boundaries/index.html)包括9份原典选读、27条定位主张、6条条件性结论、5个案例、3组可编辑图及8项精确检查；[验收记录](boundaries/validation.md)区分经验来源、本站推导与3项未执行设计。四项问题回访写入本阶段综述，旧卡保持快照。

第三阶段进入「意义与意识解释」：以功能角色、语义／理解、主体性和体验为不同目标，核对理论版本、支持与最强反方；每项桥接前提都要说明是定义、经验假说还是形而上学主张。优先沿第三轮E批的语义、意识与非经典解释问题卡建立比较，不以当前的耦合或自主性结论自动推出体验。正式站点集成仍在阶段4。第一阶段的群体数据版本复算继续留在研究队列，未被第二阶段方法核验替代。


## 第三阶段交付与第四阶段起点

[意义与意识解释工作台](meaning/index.html)完成12份指定范围选读、40条定位主张、6条条件性结论、5类案例、6项COGITATE预测比较、3组可编辑图和11项精确检查。[验收](meaning/validation.md)与[版本台账](meaning/versions.md)保留理论版本、同项目文件关系、分析偏离、样本例外与尚未审读的材料。语义与意识两张E批卡获得综合回访；量子问题只增加桥接接口，专项证据仍待补。

第四阶段可据此推进，验收顺序为：

1. **跨篇复核**：共同审查前三阶段18条条件性结论，标明稳定的推理边界、依赖争议前提的判断与开放问题；找出重复、冲突和用词不一致处。
2. **来源与版本统一**：维持作品、版本、载体和实际读段的分别记录；同项目材料不计独立证据。历史144节点与后续综合来源继续分层，建立面向读者的引用导航。
3. **正式入口与解读联动**：把经复核的综述、图与文献索引接入网站路线页；保留原工作台和编辑源，核验链接、桌面／手机阅读及项目构建。发布或部署按届时授权范围执行。
4. **研究队列排序**：前三阶段共9项设计仍未执行。按可区分性、资料可得性及复算前提排序，至少给出一个下一项实证或论证任务的明确启动条件。

进入阶段4不意味着所有原典已全文阅读，也不意味着全部15张问题卡已完成综合。GNW后续版本、IIT 3.0逐式对照、COGITATE早期注册与原始数据、量子／泛心论专项及群体版本复算仍列缺口；不能在网站文案中自动升级为完成。
