# 第六轮计划：关键缺口与反方补读

## 范围与取舍

以第五轮时24项首轮候选没有对应作品的后续阅读映射为历史基线，按核心问题相关性、区分价值、跨路线作用和可取得的原典排序。逐项记录此前状态，不以同主题不同作品冒充原作。

本轮选读4项候选：Legg–Hutter定义汇编、Marr《Vision》三层解释、Transformer原文和Kaplan规模规律；另读Hoffmann与Pearce–Song两项针对规模规律的竞争／解释工作。选择覆盖定义、机制、架构与资源预算四种问题。Minsky–Papert 1969仅取得2017序言及书目，原书正文仍未读，不计作映射。排序是编辑判断，其他20项仍未建立原作品的阅读映射。

## 交付

每份来源记录版本、实际读段、未读和未复算部分；每个节点写明问题、方法、前提、边界、原文定位和下一问。已有关系须提供来源和定位，本站比较与直接回应分别登记。新节点进入原生时间线和文献入口，当前路线缺口、全局索引的增量及第四轮相关结论的回访同步更新；旧批次、历史计数和结论原文不覆盖。

## 验收

检查24项优先队列与第五轮基线一一对应、4项映射与2项对照来源实际读段、12条定位主张、4条关系、3项原结论回访，验证20路线的全部现有节点和本轮增量、图表及内部链接，完成网站工程与桌面／手机浏览器检查。
