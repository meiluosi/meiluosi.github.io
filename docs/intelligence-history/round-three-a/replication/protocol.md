# Baird 六状态反例复现协议

2026-10-25。本文在执行数值实验前保存。复现对象为Baird《Residual Algorithms》作者网站9页PDF，末页勘误日期1995-07-15，SHA-256为 `a32e916f75e4ca626c470d24fe0a3e587c14bd10edfae686fc9edf7498831979`。采用正文图1、§3–5及式3、6–8的六状态确定性预测问题。附页的双动作Q-learning扩展、图5全部100次随机初始化与参数搜索不包含在本次复现范围内。

## 原文给定设置

- 六个状态，全部确定性转移到状态6，状态6自循环；奖励全部为0。
- 七个权重。前五个状态的值为 `w0 + 2wi`，第六个状态的值为 `2w0 + w6`，特征不归一化。
- 训练中每个转移同样频繁；直接法用TD误差乘当前状态梯度，残差梯度还对后继值求导。
- §5定义按轮更新：同一权重计算全部转移的增量，求和后一次应用。均值版本与求和版本的步长不能混用。
- 真值为零。原文§3主张特定正初值下会发散，并进一步给出了权重和状态值的符号方向。

## 本次明确选定的设置

正文未给出足以逐点复绘图5的折扣率、初始化分布、停止标准和完整代码。本次复现的是图1反例及更新机制，不声称与图5实验设置完全相同。

- 主实验折扣率0.99，步长0.01，初值为 `w0..w5=1, w6=10`。
- 同步求和的按轮更新为主；额外检查顺序1到6的逐转移更新。
- 折扣率0.9、0.95、0.99用于敏感性检查，步长0.001、0.01用于区分稳定性与步长影响。
- 直接法记录至10000轮；残差梯度记录至100000轮，并以线性迭代矩阵快速幂计算更长时间的同一递推。快速幂结果明确标注，不能记成逐轮执行。
- 原文值函数由六行七列特征矩阵给出，存在参数零空间；不要求所有权重收敛到零，以状态值和Bellman残差作为判定对象。

## 先验验收标准

1. 特征、转移和图的原文内容须视觉核对；读取范围与版本可追踪。
2. 用逐状态标量求和与独立矩阵式计算同一轮更新，误差小于1e-11；用中心差分核对残差梯度，容差1e-6。
3. 主实验直接法在状态值空间有模大于1的特征值，有限迭代出现明显增长；记录符号变化。若原文“单调／同号趋向无穷”的强表述不成立，须如实报告，不能只展示增长曲线。
4. 残差梯度的Bellman残差下降，非零特征模小于1，状态值空间的极限为零；分别报告有限步残差和真值误差，不把二者当同一指标。
5. 稳定性结论要与敏感性结果一同呈现，不能推广成所有折扣、所有步长、所有采样方案均发散。
6. 输出环境、代码、参数、结果数据、可编辑曲线和与原文逐项对应的报告。作者代码不可得时，明确是独立实现的结果复现。

## 执行前修订 A：原文式7的符号冲突

首次数值运行前，视觉检查PDF第4页发现式7写成 `+αΣδ[-∇V]`，与第2页式3的 `+αδ∇V` 相反。第3页式6与第4页式8则一致。主实现明确遵循式3的直接法，采用§5正文定义的按轮求和，并遵循式6/8的残差梯度；不能称为逐字执行式7。初始协议保存在 `protocol-v1.md`。

增加一个独立判别：在单状态、零奖励、特征为1的表格问题中，式3得到因子 `1-α(1-γ)`，逐字式7得到 `1+α(1-γ)`，后者在正步长、γ<1时发散，与原文对表格情形的叙述不符。因此把式7视为疑似排印符号错误是本次研究的判断，不冒称作者已确认勘误。结果记录保留逐字式7的状态空间谱，便于复核。其余参数、范围及验收标准不变。
