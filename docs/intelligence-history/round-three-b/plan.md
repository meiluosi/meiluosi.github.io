# 第三轮 B 批能力与评价执行计划

2026-10-27启动。研究问题是：怎样判断一个系统具有什么能力，这种判断依赖哪些任务、样本、环境和资源？本批展开行为表现、心理测量、理性与资源约束三条路线，并以这些标准回访A批。目标已设置，2026-10-27完成本计划指定范围与统一验收；未覆盖文献另列。

## 文献与评价字段

节点延续问题、机制、成立条件、主张、原文位置、局限及下一问。新增评价视角记录：测量对象／构念、任务与环境、样本或适用主体、输出指标、信度与不确定性、效度论证、先验与经验、计算和时间预算。理论文章不虚构实验样本；人口或文化比较不从单一统计结构直接推断本质差异。

关系图分别标明原文回应、明确采用、评测或方法比较及本站提出的比较。时间先后不自动构成影响。事件日期与实际阅读版本分开；选读范围、全文阅读和独立验证分别记账。

## 方法核验边界

拟验证同一可观测协方差能否来自不同潜在过程构造，并说明均值比较中的截距与潜变量均值为何需要额外约束。模型与数值条件在运行前另存协议；采用精确矩阵等式、独立标量计算及反例检查。合成数据仅用于检验数学陈述，不模拟真实人群，也不声称复现某篇心理学论文的经验结果。
