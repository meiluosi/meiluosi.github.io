# 心理测量与能力结构路线 · B批增量

Binet–Simon强调当下用途与施测条件，Spearman研究共同变化；Thurstone将单因子方法与一般能力假说分开。Gf／Gc与Carroll层级结构进一步改变能力描述的粒度，CHC把这些语言连接到测验覆盖。

Gardner、直接测验检验与过程重叠理论，让“有什么结构”和“由什么过程产生”分开。构念效度和不变性要求解释接触额外证据，不能仅凭稳定相关或高信度宣告机制与跨群体可比性。
