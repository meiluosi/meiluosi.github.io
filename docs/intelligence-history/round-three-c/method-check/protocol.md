# 预先协议：观察相关与干预

在实现前固定两个二元结构模型。模型一：U~Bernoulli(1/2)，X=U，Y=X。模型二：U~Bernoulli(1/2)，X=U，Y=U。观测分布均为P(0,0)=P(1,1)=1/2。分别切断X的生成方程，执行do(X=0)和do(X=1)。枚举外生变量，使用有理数精确计算，另以手写解析表对照。

通过条件：观察联合分布完全一致；模型一两个干预下Y的均值为0、1；模型二均为1/2；模型二在do(X=1)下必须保留Y=0的概率1/2（负控制）；结果总概率均为1。

这是可识别性的合成反例，不是神经实验或任何论文数据复现。二元、确定性、无测量误差的条件不能替代真实神经干预的特异性、补偿与网络依赖问题。
