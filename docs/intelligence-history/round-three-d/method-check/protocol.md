# 预先协议：集体平均与共享误差

在实现前固定四个估计者的误差e_i=S+I_i，S与所有I相互独立，均值零。比较三个条件：(a) Var(S)=0, Var(I_i)=1；(b) Var(S)=1, Var(I_i)=0；(c) 两者各1/2。全部个体方差都为1。解析式Var(mean(e))=Var(S)+Var(I)/4，应分别为1/4、1、5/8。

使用Rademacher变量的所有正负组合精确枚举。为避免无理数，分开枚举共享与独立成分后按方差权重组合，再用完整协方差矩阵求和独立对照。通过条件：个体方差均1；群体结果匹配三项解析值；共享误差条件不因人数增加下降；零共享条件人数4变16时方差1/16。

这是一项合成方法核验，不是Woolley群体因素的复现，不是多数表决定理，也不将均方误差等同智慧、共同善或民主正当性。

协议建立：2026-10-27；在核验实现与运行前保存。结果与后续偏离另记，协议本身不追改。
