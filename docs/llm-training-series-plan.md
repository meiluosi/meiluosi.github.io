# 大模型训练研究笔记 栏目规划

规划日期：2026-10-20。七卷、每卷六篇的范围已经作者确认，作为持续推进目标，不设置 token 预算。七卷共 42 篇中文正文及对应英文概览已完成，并于 2026-10-23 通过最终交叉审校和本地统一验收；详见[最终验收记录](./llm-training-series-final-audit.md)。实际进展见[执行记录](./llm-training-series-progress.md)。

## 栏目的主线

这个栏目重点研究大模型后训练，同时补齐理解后训练所需的数据与预训练基础。目标读者是了解基本 Python、知道模型可以训练，但还不能独立解释训练流程和实验结果的学习者。

每一卷围绕一个明确问题，不按热门名词逐个写百科：

| 卷次 | 主题 | 要回答的问题 | 预期产物 |
| --- | --- | --- | --- |
| 第一卷 | 预训练数据 | 模型应该读什么，怎样保证数据可解释 | 数据候选记录、处理配置、划分与验收设计 |
| 第二卷 | 预训练基础与小模型实验 | 文本怎样变成一次参数更新，怎样判断训练是否正常 | 最小训练流程、日志解释、基线实验方案 |
| 第三卷 | 监督微调 SFT | 怎样让模型从续写转向按要求完成任务 | 指令数据规范、SFT 基线、能力与退化评估 |
| 第四卷 | 偏好学习与奖励建模 | 没有唯一标准答案时，怎样利用比较反馈 | 偏好数据规范、奖励模型与 DPO 对照方案 |
| 第五卷 | 推理任务的强化学习 | 怎样通过采样和可验证反馈改进模型策略 | 奖励定义、PPO／GRPO 等方法的机制分析与实验设计 |
| 第六卷 | 工具调用与多步交互训练 | 模型需要采取行动时，数据、奖励和评测怎样改变 | 轨迹格式、环境接口、工具使用与多步任务对照 |
| 第七卷 | 训练评测与工程复现 | 怎样判断收益可靠，并把研究结果稳定交付 | 可复用评测流程、运行记录、成本与部署验证 |

第二卷是必要基础，第三至第六卷是后训练主体。第七卷把前面分散使用的工程方法集中整理，不是说前六卷可以先不评测。每卷从第一篇起就明确验证集、测试集、预算与基线。

已有模型基础的读者可以直接从第三卷开始，在遇到分词、mask、损失和优化问题时回查第二卷。做后训练不要求先从零训练出一个有用的大模型。

## 第一卷的改写原则

六篇沿用一个假设场景：为中文技术模型准备中英文本数据。该场景用于串联决策，不虚构数据处理经历或训练结果。

不要求每篇标题都照抄同一模板，但正文遵循研究工程学习顺序：

1. 从具体困难开始，说明为什么朴素办法不够。
2. 先用一个小例子解释方法，再给术语与必要公式。
3. 说明公式中的量、假设和实际实现的区别。
4. 用失败案例说明适用边界。
5. 引入改进方法，同时解释它增加的成本或偏好。
6. 给出可比较的实验问题，明确哪些条件应保持相同。
7. 用两个问题收尾：一个检查原理，一个要求设计下一步比较。

“更直白”不等于删掉技术细节。第一篇保留中英文数据集和版本口径；第四篇保留 MinHash 与 LSH 推导；第五篇保留 token 权重和覆盖率；第六篇保留代码与记录格式。改变的是解释顺序、句子负担和例子的连续性。

主要结论通过措辞和少量表格区分：发布方报告、假设下的推导、工程设计、需要实验验证的判断。不把每段都写成免责声明，也不用虚构的“踩坑经历”制造亲历感。

方法参考：[research-learning 技能](https://github.com/meiluosi/research-learning/blob/main/skills/research-learning/SKILL.md)、[结论状态说明](https://github.com/meiluosi/research-learning/blob/main/skills/research-learning/references/claim-status.md)、[写作交接说明](https://github.com/meiluosi/research-learning/blob/main/skills/research-learning/references/handoff.md)。这是对方法的写作适配，不是机械复制课程模板。

## 第二卷 预训练基础与小模型实验

本卷用六篇把数据交给训练。只讲后训练真正会用到的基础，不另开一个无限延伸的架构百科。

| 拟题 | 具体问题 | 示例或验证设计 |
| --- | --- | --- |
| 01 文本怎样变成 token | BPE、词表和特殊 token 各解决什么；中文为何可能切得更多 | 同一段中英混排文本，在固定分词器下逐项查看切分和长度 |
| 02 语言模型究竟在预测什么 | 输入和标签怎样错位；交叉熵为何惩罚低概率正确答案 | 手算一个极小词表的损失，检查标签偏移一位的例子 |
| 03 一次前向计算怎样处理上下文 | embedding、因果注意力、位置与输出层怎样连接 | 用小序列画出信息能否流向未来位置，追踪张量形状 |
| 04 训练块怎样组成一个 batch | packing、EOS、padding、attention mask、loss mask 有何区别 | 同一批短文采用两种打包方式，对比有效位置与边界 |
| 05 训练为什么会不稳定 | batch、梯度累积、学习率、优化器、精度和裁剪分别影响什么 | 从一个稳定基线出发，每次改变一项，预先说明应观察什么 |
| 06 怎样完成一个可解释的预训练实验 | 怎样看训练损失、验证损失、生成样本、吞吐和恢复 | 先通过极小样本过拟合与恢复检查，再设计正式基线 |

**本卷结束条件**：读者能解释一个 batch 到一次参数更新的主要路径，知道读取 token 与有效 token 的区别，能区分程序运行成功、学会小样本、验证集改善和实际任务能力。

极小模型主要验证计算与工程逻辑；后续 SFT 和强化学习可使用有基础能力的开放权重模型。两者不能混成一个“从零训练已经达到应用效果”的叙事。

## 第三卷 监督微调 SFT

本卷的核心不是“把训练命令跑起来”，而是理解我们在让模型模仿什么。

| 拟题 | 主要问题 |
| --- | --- |
| 01 预训练模型为什么不总按指令回答 | 续写目标与任务示范有什么联系，SFT 在改变什么 |
| 02 一条指令样本应该包含什么 | system、user、assistant、多轮边界与任务定义怎样组织 |
| 03 哪些 token 应该计算损失 | 全文训练、只训练回答与多轮 assistant mask 怎样改变监督信号 |
| 04 指令数据怎样选和生成 | 任务覆盖、答案正确性、合成数据审核、去重与来源追踪 |
| 05 全参数微调与 LoRA 怎样选择 | 可训练参数、显存、适配能力与量化带来的取舍 |
| 06 怎样判断 SFT 改善了什么 | 格式遵循、任务正确率、拒答边界、通用能力与过拟合怎样分别评估 |

**贯穿场景**：选择一个边界明确的中文任务，例如依据给定材料做结构化提取。保留错误类型，区分“输出格式正确”和“内容正确”。不把所有问题归为“模型不听话”。

**交付目标**：可定位版本的指令集、固定聊天模板、明确的 loss mask、训练基线和按任务拆分的评价。

## 第四卷 偏好学习与奖励建模

从 SFT 的示范答案过渡到“两个答案哪个更符合要求”。这一卷先解释反馈含义，再讲优化公式。

| 拟题 | 主要问题 |
| --- | --- |
| 01 标准答案不唯一时 怎样提供训练信号 | 示范、排序、分数和规则反馈分别表达什么 |
| 02 偏好对怎样构建 | chosen/rejected 的差异是否有效；长度、风格与标注者偏好如何干扰 |
| 03 奖励模型怎样从比较中学习 | 成对排序目标、分数的相对意义与分布外失效 |
| 04 DPO 为什么能直接使用偏好对 | 从目标与参考策略的关系理解公式，解释 beta 和序列概率 |
| 05 离线偏好优化与在线采样有什么区别 | 固定答案池与不断生成新答案，各自解决什么又遗漏什么 |
| 06 偏好分更高 为什么未必任务更好 | 长度偏差、奖励过度优化、评审模型偏好与独立测试 |

**交付目标**：一组标签定义明确的偏好样本、可解释的 SFT/DPO 对照及独立任务评测。没有可靠偏好标准时，先完善标注标准，不急于换算法。

基础研究入口包括 [InstructGPT](https://arxiv.org/abs/2203.02155) 和 [DPO](https://arxiv.org/abs/2305.18290)。前者可用于认识示范、排序反馈与强化学习的衔接，后者用于研究直接偏好优化的设计；实际正文需要进一步读取相关方法与实验章节，不从摘要泛化出普遍效果。

## 第五卷 推理任务的强化学习

本卷把“模型写出答案，环境给出反馈，再更新模型”拆开。先理解采样与目标，再比较算法，避免直接从复杂训练框架入手。

| 拟题 | 主要问题 |
| --- | --- |
| 01 语言模型怎样构成强化学习问题 | 状态、动作、轨迹、奖励与策略分别对应什么 |
| 02 奖励究竟检查了什么 | 最终答案、代码测试、格式与过程信号的覆盖范围 |
| 03 策略梯度为什么能提高高奖励答案的机会 | 从采样概率与 log probability 推导基本更新，解释 baseline |
| 04 PPO 在限制怎样的更新 | 概率比、裁剪、价值估计与参考约束分别起什么作用 |
| 05 GRPO 怎样利用同题多次回答 | 组内比较、优势估计、奖励无差异与长度处理问题 |
| 06 怎样解释强化学习的成功与失败 | 采样预算、奖励漏洞、熵变化、训练稳定性与独立泛化 |

**贯穿场景**：有可执行检查器的有限任务，例如简单程序或可核对答案的题目。先明确检查器能证明什么，避免把“通过检查器”当成所有维度都正确。

[DeepSeekMath](https://arxiv.org/abs/2402.03300)作为 GRPO 的研究入口之一。实现调研可参考 [TRL 官方文档](https://huggingface.co/docs/trl/index)，正文需固定所用版本，并区分论文目标、实现选项和后续变体。本规划不预设某个算法在本地任务上获胜。

## 第六卷 工具调用与多步交互训练

单次答案变成多步行动后，错误来源更多：模型、工具、环境状态、反馈和恢复都有可能出问题。

| 拟题 | 主要问题 |
| --- | --- |
| 01 工具调用样本为什么不是普通问答 | 调用、参数、返回值与后续行动怎样组成轨迹 |
| 02 怎样用 SFT 学会工具接口 | 语法有效、参数合理和任务完成如何分开监督 |
| 03 多步任务的奖励应该给谁 | 终局奖励、过程信号、失败恢复与信用分配 |
| 04 环境和数据怎样保证评测独立 | 重置、随机性、任务实例、状态泄漏和可复现轨迹 |
| 05 失败轨迹怎样用于下一轮训练 | 错误分类、重试、自纠正与数据筛选的作用边界 |
| 06 如何评估一个工具使用模型 | 成功率、工具成本、步数、超时和约束遵循如何共同报告 |

**交付目标**：先选择一个可控环境，打通任务、工具接口、轨迹日志与评价，再决定是否值得引入强化学习。不给模型增加工具就宣称获得了更强推理能力。

## 第七卷 训练评测与工程复现

前六卷每篇都评测；本卷把已出现的做法整理成可以复用的工程方法。

| 拟题 | 主要问题 |
| --- | --- |
| 01 怎样设计能回答问题的对照实验 | 假设、基线、控制变量、重复实验与失败判据 |
| 02 基准、人工评价和模型评审各自测到了什么 | 污染、提示、采样、评审偏差与统计不确定性 |
| 03 怎样分析一项训练改动的成本 | token、FLOPs、墙钟、峰值显存和额外数据成本 |
| 04 为什么换一套训练环境结果会变 | 精度、并行、数据顺序、算子与恢复语义 |
| 05 模型交付时怎样保持训练时的行为 | 模板、特殊 token、量化、推理参数与回归测试 |
| 06 怎样积累可复用的实验结论 | 版本化数据和模型、失败记录、可比较报告与下一轮决策 |

**交付目标**：让读者能说清一次改动在哪些条件下有效、成本是多少、哪些现象还不能解释，而不是只保存最好的一个分数。

## 专项内容如何扩展

代码与数学数据、长上下文、多模态、蒸馏和持续学习先作为候选专题，不提前承诺每个都扩成一卷。遇到明确研究问题、已有足够材料时，再决定放入主线还是单独成篇。

避免两种失控：为了追热点不断插入新算法；为了“讲完整”迟迟不进入后训练。第二卷完成后，优先推进 SFT，再进入偏好与强化学习。

## 怎样推进写作与实验

不预设每篇都必须出现真实训练结果。文章可以是方法解释、实验设计或实验报告，但要明确是哪一种。一个计算示例的正确，不能代替整个方法的训练证据。

每卷先完成主题与问题清单，再写前两篇，用它们检查术语密度、例子连续性和公式解释方式。随后补齐其余篇目，不把整卷写成六个互不衔接的论文摘要。

每篇至少保留一个具体例子、一个失败情况、一个可比较的问题。比较涉及训练时，先写预测和预算，再执行；报告结果时保留不符合预测的现象。正式实验使用的模型、设备和训练规模需根据实际可用资源确定。

本期七卷写作、逐篇交叉审校和统一页面验收均已完成。后续根据读者反馈与实际实验新增证据，不把教学算例自动升级为训练实测；不新增网站阅读路线模块。
