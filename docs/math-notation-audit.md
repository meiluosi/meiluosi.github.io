# 数学符号审计与存量基线

`pnpm audit:math` 列出正文中疑似裸露符号；它是启发式扫描，不代表每个结果都是真正的数学公式，也不能发现所有 ASCII 伪公式。`node scripts/audit-math-notation.js --strict` 在有任何候选时失败。CI 使用 `node scripts/audit-math-notation.js --baseline`，允许 `scripts/math-audit-baseline.json` 中已记录的行，不允许新增或重复候选。

本轮从 86 个候选中修正了 60 个明确的数学记法候选，并规范了一处混合专名行中的概率；其余 26 行保留在基线，按专名、图片替代文字、自然语言比较或参数标识分类。分类供人工复核，并不表示存量中的数学问题可以长期忽略。图片替代文字尤其不能盲目加入 LaTeX：应在保持读屏可理解的前提下改写。

基线按文件路径、完整的去除首尾空白的原始行和出现次数匹配，行号变化不会造成误报；任何行内改写都会触发复核。修复候选后，从 JSON 中删除对应记录；若是确认的误报，记录具体类别和原文并经代码审查。不要批量接受新增候选。运行基线模式时，已消失的记录会显示数量，提示清理。

审计当前只覆盖中英文文章 Markdown / MDX；基线不覆盖其他内容类型，也不保证数学推导正确或 LaTeX 可渲染。对正文的数学改动仍需通过构建及页面检查。
