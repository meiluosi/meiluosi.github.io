# 代表页面性能与交互验收

每周及手动运行的 `Performance Baseline` 工作流同时记录桌面样本和移动端模拟样本。移动端覆盖首页、Transformer 文章、知识图谱和 Transformer 实验室，每页运行三次；Lighthouse 默认移动端模拟包含限速和 CPU 减速。报告保存在工作流 artifact 中。现有 0.7 性能与 0.9 无障碍分数仅为告警线，沿用桌面基线，**不是实测校准后的承诺或发布门槛**。收集数次稳定结果后，再结合实际设备体验设置页面级传输量和交互预算。

Lighthouse 分数不能代替逐项检查，也不提供可靠的真实设备内存上限。复验时记录设备、浏览器、网络、冷缓存与缓存状态；分别检查初始访问和读者打开交互功能后下载的资源。阅读助手的 WebLLM 缓存检查在打开面板后执行，模型初始化由用户打开面板触发；不应把构建中最大文件大小当作每个页面的初始下载量。

对上述四页和新增交互，使用键盘完成导航及主要操作，检查焦点、状态名称与退出路径；用实际读屏软件核对结果变化，分别检查减少动态效果、窄屏和 WebGL 不可用时的降级。自动无障碍评分不证明这些路径可用。任何不能实际运行的设备或辅助技术应在验收记录中标明，不能记为通过。
