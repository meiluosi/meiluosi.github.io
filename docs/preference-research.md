## 技术边界

- chosen 是一对回答中的相对选择，不保证达到任务合格线；两者均差、平局、无法判断分别处理。
- 同一排序中的六个偏好对不能视作六份独立证据；划分与统计按原始提示及来源分组。
- 共同上下文需检查序列化和 token 边界；截断可能删去真正导致偏好的差异。
- 奖励模型估计的是指定比较分布下的选择概率，不是事实正确概率。
- 分数对提示相关平移不敏感；缩放会改变 sigmoid 概率，不能误写成任意单调变换保持概率不变。
- 单条损失的局部梯度方向不等于共享网络对所有输入都保证同样变化。
- 使用软标签的最优概率推导限定为可独立拟合、无额外正则的情形；不确定标签不能直接等同平局。
- 偏好准确率、概率校准、分布外泛化、实际任务收益分别验证；不将训练器默认指标写成完整评价。

## 2026-10-23 最终审校：04 DPO

核对 DPO v3 第 4 节与附录的 KL 正则目标、参考策略加权的最优解、Bradley–Terry 重参数化；核对 TRL 0.23.1 参考预计算、beta 和 IPO 文档。Likelihood Displacement v4 只引用摘要支持的现象，不转述未复核实验数字。

本轮发现并修正中英文原文的实质错误：最优策略漏乘参考概率；KL 项缺少明确的提示平均；参考策略被说成能阻止绝对概率下降；beta 梯度被描述为全局单调或成正比；序列贡献被错误平分；标签因策略改变自动失效；固定奖励被误写成期望奖励不随策略变化。概率下降反例补齐另两条序列，使分布归一化。明确局部标量导数不能保证共享网络每条偏好都改善。

`validation/preference-volume-2026-10-20/check_dpo.py` 与 `dpo-audit.json` 检查各 beta 损失及有限差分导数、beta=100 的饱和反例、两个 token 不等贡献、归一化概率反例及 J(q)=beta log Z−beta KL(q||pi*) 恒等式。没有训练模型。
