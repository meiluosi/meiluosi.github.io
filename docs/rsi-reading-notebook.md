## 智能手记

`/rsi/` 保留既有地址，内容改为三段相连的阅读：

1. **这次改变了什么？** 区分搜索统计、模型参数、产生改进的方法。点击切换是一幅概念图，不计算模型能力，也不宣称实现递归自我改进。
2. **换一道题，原来的本领还在吗？** 实际执行颜色、位置和形状三种固定规则，在换颜色、换位置、换目标时计算逐项匹配。没有模型训练，不能充当 AGI 测试。
3. **谁决定什么叫更好？** 用显式设定的教学案例比较不同错误与代价。一次选择会改变可见结果，并追问测量没有包含什么。

三类实验分别补上“先猜一猜”的观察入口，连接到相应手记章节；案例与阅读路线也可返回主线。共享探索页提高阅读字号。保留普通文档导航，不引入自动滚屏、常驻动画或新的三维依赖。

## 每篇解读的完成标准

| 阅读环节 | 博客需要回答的问题 | 核对依据 |
| --- | --- | --- |
| 原文身份 | 读的是哪一版、谁写的、何时发表？ | 标题、作者、版本日期、DOI/arXiv、会议或期刊 |
| 问题背景 | 作者想解决什么困难？为什么旧办法不足？ | 引言与问题定义，区分作者论点和本站判断 |
| 关键方法 | 输入、状态、反馈、更新、停止条件分别是什么？ | 正文方法、算法、公式；必要时核对公开代码版本 |
| 读者直觉 | 用一个小例子能看到哪种差异？ | 独立构造且明确标注教学模型；不伪装成论文实验 |
| 证据强度 | 数据、基线、预算、划分、消融和统计条件是什么？ | 实验章节、对应图表和附录，数字附定位 |
| 结果解释 | 哪些主张被支持？替代解释有没有排除？ | 每项结论与对应对照、评估设置绑定 |
| 局限与失败 | 什么没测？哪些条件会让结论失效？ | 作者限制＋单独标注的分析；不夸大阴性结果 |
| 与其他论文关系 | 改变的是模型、搜索、记忆、工具、数据，还是改进机制？ | 术语与任务范围对齐后比较，不混合排行榜 |
| 复现边界 | 哪些只由论文报告，哪些在本站运行？ | 原始日志、配置、样本、代码；没有复现便明确说明 |
| 留下的问题 | 下一步怎样检验，而不仅是“扩大规模”？ | 提出可区分解释的实验与所需资源 |

正文以问题推进，不要求每篇机械套用同一组标题。概念型论文重点解释定义、假设、论证和反例；经验型论文重点解释方法、实验、对照与误差。不能因为没有实验表就虚构量化证据。

## 文献台账字段

- 原始批次及来源位置、原文题名、作者、年份、版本、稳定链接、公开代码。
- 全文可访问性与实际阅读范围：摘要／正文／附录／代码。
- 核心主张、支持它的章节／图表、实验条件、未解决问题。
- 中文文章路径、英文版本类型（全文或概览）、系列顺序、关联手记与实验。
- 状态分别记录：已定位 → 全文已核对 → 解读已写 → 事实复核 → 页面验证；不把检索完成计为解读完成。

## 最终综述的组织方式

综述由实际集合决定覆盖范围，不预先宣称穷尽 RSI／AGI 文献。读完后围绕以下比较建立证据表：

- 改进发生在哪一层，哪些部分固定，谁提出候选，谁选择候选。
- 反馈的来源与可靠性；评估是否参与优化，留出任务与跨分布证据是否存在。
- 学习、搜索、适应、元学习和递归自我改进之间的关系与分歧。
- 能力广度、学习效率、自主程度和资源成本分别有什么证据。
- 共同失败模式、彼此矛盾的结果，以及可由一个小规模实验检验的开放问题。

综述提供两种入口：先读总图再深入单篇，或逐篇阅读后回到比较表。每篇文章反向链接综述、相关原文和相邻问题。中文博客遵循现有 content collection；英文概览必须标明概览，不冒充完整翻译。
