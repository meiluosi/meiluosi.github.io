# 网站标题、导航与文献卡片调整

日期：2026-10-16。

## 本轮范围

按用户反馈调整网站的标题表达与阅读功能：缩小展示型大标题，采用明确的研究主题和功能名称；撤下阅读收藏、阅读路线、文章反向链接及延伸阅读推荐；将文献架改成可交互的小卡片。

## 实现

- `src/styles/site-typography.css` 统一标题比例：页面标题 26–34px，章节标题 21–25px，三级标题 19px，文献卡片标题 16px。集中规则覆盖原有页面的大字号，避免各页继续扩大标题。
- 首页、文章目录、作品、关于、RSI、研究岛、实验室、案例详情及模型训练阶段采用具体主题标题；对应英文同步更新。文章正文与技术结论保持原有内容。
- 移除 `SaveNote`、`SavedReading`、`ReadingPathCards`、`NextReading` 和 `ArticleConnections` 组件，以及收藏存储工具和路线数据；删除各页面与菜单中的对应入口。
- `/reading/` 与 `/paths/` 旧地址转向文章目录，三条旧路线详情转向对应实验页，不再显示原模块。
- 文献架保留原有 8 项资料，按模型与训练、搜索与强化学习、因果推断与评估分类。使用蓝色渐变、半透明边框、图标、编号和紧凑卡片，参考用户提供的图片。
- 卡片支持主题筛选、关键词搜索、空结果提示、原生键盘展开、原始资料链接、相关笔记及锚点直达。无 JavaScript 时仍可展开卡片阅读。
- 评论继续保持关闭。

## 验收

- `pnpm check`、`pnpm type-check`、`pnpm build` 通过；Astro 检查为 0 错误、0 警告，另有 4 项既有提示。
- 生产预览验证 16 个桌面页面与 4 个 320px 手机页面，包括中英文文章；无横向溢出、无页面脚本错误，页面标题分别不超过 34px 与 26px。
- 文献架的主题筛选、关键词搜索、空结果、键盘展开、英文显示和锚点展开均通过；旧收藏与路线地址正常跳转。
- 扫描生成页面的 2637 个站内链接属性，无断链，无指向已撤下模块的入口。`git diff --check` 通过。

## 后续精简：标题与透明卡片

根据下一轮反馈，主要页面顶部仅保留标题，删除文章索引的随笔推荐、智能手记邀请、起读推荐以及首页／作品页的重复随笔推荐。个人简介和案例信息保留在正文区。

文献架改为与站点背景协调的鼠尾草绿、暖白透明表面。文章索引共用这一配色，默认卡片模式，可切换列表；本地记忆显示偏好，存储不可用时仍能切换。两种模式共用搜索、筛选、空结果与返回状态。

验证涵盖 1440、752、320px 三种宽度的卡片／列表、筛选、全文搜索、清空、刷新后偏好保留，以及英文与键盘操作；另检查 10 个主要页面的精简页头。无页面脚本错误与横向溢出。静态检查、类型检查和构建通过，2599 个站内链接属性无断链。
