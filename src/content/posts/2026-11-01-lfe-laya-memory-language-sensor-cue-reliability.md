> **先说边界：所有数字来自我自己写的模拟器，没有一个来自真实动物或真实环境。** 世界是"六种食物、规则反复反转"的小世界；线索句子是我或同一个 LLM 写的；LLM 的判断是预先算好并缓存的。结论是"在这类模拟里什么成立、什么不成立"，不是"AI 学会了适应真实世界"。

## 一句话结论

一群虚拟小生物在规则会突然反转（原来能吃的变有毒）又变回来的世界里觅食。我事先写下判据，用 21 批预注册评估检验了三件事，**得到三条比较稳的结论和几条老老实实的阴性结果**：

1. **记忆结构让它们记得住旧环境**：普通学习者在旧环境回来时反而比第一次更差，给它加一个"按预测误差另开一页信念表"的结构后，能把这个负数变成正数；在 16 个全新训练种子、独立来源的数据、两倍食物种类下全部复现。
2. **LLM 当"语言传感器"有大收益，当"决策者"没用**：让它直接决定何时切换记忆没有帮助；让它判断"这两句话描述的是不是同一类天气"，并把判断当作带噪声的传感器并入贝叶斯推断，收益最大——但传感器读错 30% 时优势消失。
3. **先天信任要在"有人骗它"的历史里进化**：在线索永远可靠的历史里进化出的个体完全信任线索，线索一误导就崩；在混合历史里进化的个体留有余地，处处都稳。**一生内再估计线索可靠度没有帮助**——与我事先的预测相反。

## 做了什么（尽量短）

- 世界：K 种食物，一半营养一半有毒，个体只读到一句文字描述；每隔一个阶段，所有食物的效果反转。固定的预训练决策模型（Laya）给每句描述一个"能不能吃"的先验；个体一生内学习；**先天参数（基因组）由进化决定**，先天、后天、Laya 感知三个来源分开标注。
- 核心指标"**节省**"：旧环境回来后，前两个窗口里吃到营养食物的比例，减去第一次进入该环境时的比例。**正数 = 记得住，负数 = 旧知识被新经历冲掉了。**
- 纪律：每批比较先冻结协议和判据，再训练，训练后对基因组打 SHA256 哈希，最后**一次性评估**；git 提交就是时间戳。偏离、中断、命名事故全部记录在案。

## 发现一：分账本的记忆结构让个体记得住

![节省：普通学习者、概率化对照、环境分段记忆](/lfe-laya/fig1_retention.png)

环境分段记忆（regime）最多维护 4 张环境信念表，按预测误差新开或切换。在独立来源的蘑菇数据（UCI Mushroom，CC BY 4.0，可食/有毒标签来自真实数据）上、16 个全新训练种子下：

| 比较（16 个种子） | 差值（预设阈值） | 方向一致 |
|---|---|---|
| A/B/A：regime 节省 − 普通学习者 | **+0.250**（≥ +0.15） | 16/16 |
| 多次反转 A/B/A/B/A | **+0.205**（≥ +0.15） | 16/16 |
| 部分反转 | **+0.141**（≥ +0.05） | 16/16 |
| 食物种类翻倍（K=12） | **+0.365**（≥ +0.10） | 16/16 |
| regime 不比概率化对照差（非劣效） | **+0.131** | 16/16 |

两件事值得单独说：**这个数据集上 Laya 的先验完全没有区分力（AUC 0.505）**，保留的收益依然存在——功劳在记忆结构，不在语言模型；以及这个概率化对照（潜在原因推断的一个简化在线近似）的节省几乎是 0 或负，**它只能代表我实现的那个近似，不能代表这一类方法**。

## 发现二：把 LLM 当传感器，而不是当决策者

我先试了"直接让 LLM 决定"：意外触发时，把个体最近几餐和各张表的预期交给 LLM，让它回答"保持 / 新开 / 切到第几张"。两轮开发期实验（2916 和 1216 次调用）里它的节省比"同样触发、但用规则动作"低 0.05 到 0.20——**没有任何收益迹象**。打乱结果会让它变差，说明它确实在读经历，只是读得不比普通学习好。

换一个问法：**这两句话描述的是不是同一类天气？**（"天气温暖无风、地面干燥" vs "炎热无风，土壤皲裂"。）LLM 在 18 条措辞完全不同的评估句上三项门槛全过（准确率 1.0，配对 AUC 1.0，对无关句 AUC 1.0）；Laya 自己的隐状态向量（0.33）和问答特征（0.83/0.89）都没过。

于是把 LLM 的句对判断预先算好缓存（36 句线索共 630 对），当作**带噪声的传感器**并入贝叶斯环境推断：线索句子一变，就给各个环境一个似然因子 $f=r\,s+(1-r)(1-s)$（$s$ 是句对相似概率，$r$ 是传感器可靠度，由进化决定）。世界里同一个状态每次出现措辞都不同，所以按字面匹配的记忆没用。

![语言传感器：节省与适应度](/lfe-laya/fig2_language_sensor.png)

| 条件（蘑菇数据，16 个种子，A/B/A） | 节省 | 适应度 |
|---|---|---|
| 普通学习者 | −0.11 | 0.73 |
| 环境分段记忆 | +0.11 | 0.81 |
| 按句子字面分表的记忆 | +0.07 | 0.90 |
| 贝叶斯推断，传感器关掉 | −0.11 | 0.73 |
| **贝叶斯推断 + LLM 传感器** | **+0.25** | **0.90** |
| 预言机传感器（用真实状态，仅作上限） | +0.25 | 0.90 |
| 打乱的传感器 | −0.09 | 0.71 |
| **30% 判断被取反** | **+0.02** | **0.74** |

读法：①**关掉传感器就回到普通学习者的水平**，全部收益来自语言证据；②**打乱传感器大幅退化**，所以不是"有线索变化就行"；③按字面分表的记忆适应度也高，因为每换一句话就新开一页，等于每个阶段重新学一遍，**没有保留**；④9 个假设里 8 个成立，**不成立的是"传感器读错 30% 时仍不比不用差"**——+0.008，没达到 +0.02 的阈值。

## 发现三：先天信任必须在"被骗"的历史里进化

传感器会错怎么办？生物的答案大概是"进化史里就有不可靠的线索，所以天生就留了怀疑"。我检验了这个类比：稠密交替的世界（每 300 步反转一次），两条线索通道各自独立地处在"可靠 / 30% 误导 / 完全无信息 / 不存在"之一，个体事先不知道；比较进化时的"历史"：

![先天信任：干净历史 vs 混合历史](/lfe-laya/fig3_reliability.png)

- 在"线索永远可靠"的历史里进化的个体，对线索的先天信任进化到 **0.99**；线索一误导（30%），适应度只有 **0.68**（混合历史的个体在同样条件下是 0.91），**完全没有线索时只剩 0.26——比根本不读线索（0.40）还差**。
- 在混合历史里进化的个体，信任降到 **0.91**；误导时 0.91，没有线索时仍有 0.82；线索可靠时只比干净历史差 **0.009**；对训练里**从没出现过的误导强度**（15%、45%）也成立（+0.528）。
- **意外的反例**：我预测"可靠度因世界而变时，一生内的在线再估计才有额外价值"。结果相反：再估计平均比"只靠先天"略差（−0.031，8 个种子里 7 个为负）。可能的原因都没检验——数值证据本来就能在后验里纠正误导的线索；我的一致性检验有噪声。**这只对我实现的这一种更新成立。**
- 第二条独立线索通道有帮助（+0.047，7/8 个种子为正），但**差 0.003 没达到预先写的 +0.05 幅度**，按规则记为未达。

## 没成的

- **优势没传到会繁殖的种群**：让个体繁殖、孩子继承先天类型，记忆结构在种群存续、规模、恢复上没有可检出的优势（建立率 +0.016）。基因变异下也没有看到选择方向。
- **没有证据说 Laya 理解环境变化**：两次探针都没过预设门槛。
- **早期的大效应没有复现**：最初预注册里的一个大效应，在 3 个训练种子的重复里没有稳定复现。
- Laya 这个预训练先验的价值是有条件的：后果延迟 40 / 80 步时 +0.049 / +0.073（8/8），即时反馈约 0，世界简单到靠经验就能学会时为 0。

## 如果只带走三句话

- 想让生命体记住旧环境，**给它一个会"另开一页"的记忆结构**，比加更强的先验更管用。
- **让 LLM 做它擅长的事（判断两句话是不是一回事），别让它做它不擅长的（对带噪声的少量样本做序贯判断）**；并且要把它的输出当带噪声的传感器，而不是指令。
- **先天的怀疑要在被骗的历史里进化出来**；"一生内再估计"在我的设置里没有帮上忙。

## 局限

- 世界是人造的：六种食物、两个状态的交替；蘑菇数据的描述是按真实记录的属性套固定模板拼成的，不是自然文本。
- 线索句由我（作者）或同一个 LLM 写；传感器是 LLM 的缓存判断，没有测过别的模型或提示；"两条通道独立"指的是缺陷抽样独立，不是信息源独立。
- 我没有与 EWC 这类神经网络持续学习方法比较。在这个世界里信念是逐描述的表格，没有共享权重，所以"保护重要权重"对应的是降低遗忘——这是论证，不是实验。
- 种子数 8 到 16，8 个种子下 Holm 校正很严；多个解释是假说，没有检验。
- 并行度很高的评估期间机器负载很大，未影响结果；一次命名事故（我误覆盖了旧学习器的源文件）已从版本历史恢复，在评估前处理，未改变任何假设。

## 可复现性与披露

- 代码（Apache-2.0）、数据与文档（CC BY 4.0）都在 [github.com/meiluosi/lfe-laya](https://github.com/meiluosi/lfe-laya)：每个预注册的协议、冻结提交、基因组哈希、原始结果与评估脚本都在 `docs/PREREGISTRATION_*.md` 与 `experiments/` 下；关键三批是 [预注册 20](https://github.com/meiluosi/lfe-laya/blob/main/docs/PREREGISTRATION_20.md)、[21](https://github.com/meiluosi/lfe-laya/blob/main/docs/PREREGISTRATION_21.md)、[22](https://github.com/meiluosi/lfe-laya/blob/main/docs/PREREGISTRATION_22.md)；论文草稿在仓库的 `paper/`，**没有上传 arXiv**。
- 模型权重不随仓库分发；LLM 传感器用 DeepSeek 的 `deepseek-flash`（思考关闭）缓存的判断，评估时不再调用 LLM，所有调用按内容哈希存档，可严格回放；LLM 调用没有预算上限（总计约一万次不同调用）。
- **本项目的大量代码、实验与文档由 AI 编码助手（Claude）在我的指导下完成**：我设定研究问题、决定取舍、审阅协议与结果；所有数字追溯到仓库里的原始结果文件。引用经过元数据级核对，具体论点只核对到摘要层面。
